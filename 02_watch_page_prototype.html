2
H1 标题
SEO 核心元素
规范：含产品名 + "Demo" / "Setup" / "Tutorial" 类词
数据源：watch_page.h1_title
3
主视频
关键：
• 必须 ≥ 30 秒
• 首屏可见，且占屏 60%+
• 自动播放、初始静音播放、循环播放
• 带 VTT 字幕
• OSS 自托管，不要 YouTube embed
数据源：
• video.src ← watch_page.watch_video_url
• video.poster ← watch_page.thumbnail_16x9
• <track> ← watch_page.caption_vtt_url
4
CTA 按钮 → 详情页
导流转化的核心
含现价与划线价信息（如 $799 $499），增加点击动机，价格与产品详情页初始展示一致
数据源：
• 链接 ← 通过 watch_page.product_id 关联 oc_product 取 SEO URL
• 价格 ← oc_product.price
5
About This Video（描述）
至少 100 字符
必须在 HTML 中可见，不只是 JSON-LD
数据源：
• 段落 1 ← watch_page.description_para_1（必填）
• 段落 2 ← watch_page.description_para_2（选填）
6
Chapters（章节）选填
对应 JSON-LD 的 Clip + SeekToAction
搜索结果可能显示"跳转到第 X 秒"
数据源：watch_page_chapter 表，按 sort_order 排序
7
Transcript（完整字幕）
• SEO强烈建议，Google 能读字幕文本 = 免费 SEO 文本量
• 视觉上可用 details 折叠，但 HTML 必须有
数据源：解析 watch_page.caption_vtt_url 文件后渲染
8
侧边栏视频列表
• 提升站内停留 + 内链
• All：展示已发布所有视频，按发布时间降序排列，无则隐藏该列表，视频区域自适应占位
• Recommend：取对应产品relative product对应的已发布视频，无则隐藏该Tab
数据源：
• 优先：watch_page_related 表手动配置
• 回退：按同类目 oc_product.category 自动推荐
