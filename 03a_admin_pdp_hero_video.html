UI Annotations
1
产品配置详情页新增 Tab: Hero Video
位置：Image 之后、Discount 之前。仅控制详情页主视频，与 SKU 价格/库存解耦。
数据库：整个 Tab 数据存入新表 product_hero_video，以 product_id 1:1 关联 oc_product
2
Video File
上传本地视频，至 OSS /videos/hero/{slug}.mp4
数据库字段：hero_video_url VARCHAR(500)
3
Video Title · 50-100 字符
含产品名 + 卖点。
错误示例：video1 / Untitled
数据库字段：video_title VARCHAR(200) · 用于：JSON-LD 的 name
4
Video Description · 100-300 字符
描述视频内容（不是产品描述），含 1-2 长尾关键词。
数据库字段：video_description TEXT · 用于：JSON-LD 的 description
5
自动获取（文件上传、更新后自动获取更新，不可编辑）
• Duration (sec)：视频时长
• Upload Date：视频上传/更新时间
• Width (px)：视频文件宽度
• Height (px)：视频文件高度
• File size (MB)：视频文件大小
• File Type：视频文件类型
6
Thumbnails — 3 Ratios (Mandatory)
• 16:9 → 视频搜索
• 4:3 → 移动端
• 1:1 → 视频徽章
WebP/JPG · 每张 < 200KB
数据库字段：thumbnail_16x9 / thumbnail_4x3 / thumbnail_1x1
7
Create Watch Page Button（2期）
1、点击后，在新增的Video模块创建记录，自动预填以下Video模块的 6 项字段：
• Linked Product（填入本产品的 产品名（Model 编码））
• URL Slug（填入产品名 slug + -demo）
• H1 Title （填入本页的 Video Title 值）
• Publish Date（初始值填入创建时间当天）
• 3 Ratios（初始值分别填入本页面 3 ratios）
• Keyword Tags（填入本页面的 Keyword Tags 值）

以上需支持双向同步

若以上6项字段值均无，则不支持创建，提示：Oops! Please complete all required fields.

2、状态值展示联动：Not Created / Draft / Published 三态。
保存后，隐藏处理逻辑
前端 JS 实时 + 后端二次校验
✓ Title 50-100 chars, description 100-300 chars
✓ All 3 thumbnails uploaded
✓ OSS URL publicly accessible
