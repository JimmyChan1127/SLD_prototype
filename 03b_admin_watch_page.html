📌 Videos 模块 列表页 说明索引
1
Catalog 新增 Videos 模块
• 全站 Watch Page 统一管理入口。与 Product 编辑页中的 Hero Video 区分。
• 支持一键导出全部数据。
数据库表：watch_page
2
支持多为筛选
快速定位SEO不友好项：
• Status：支持筛选 Published（已发布）、Draft（草稿）、Not Created（未创建），初始默认All
• Category：支持根据产品品类筛选，数据源Categories
• Missing：支持筛选 No Captions（无字幕）、No Chapters（无章节）、No Description（无介绍），初始默认Any，不作筛选
• 支持按产品名 或 Model编码精准搜索，注意自动去除空格
3
视频列表
可视化管理视频列表：
列表与全站产品列表实时同步
• Product：展示 产品名 + Model编码
• Status：展示视频状态，包括
>> Published：已向谷歌发布的视频
>> Draft：编辑中未向谷歌发送的视频草稿
>> Not Created：未在产品配置页触发创建或在Videos模块中未经点击Creat的产品
• Video：视频文件是否为空，否“✅”，是“-”
• CC：字幕文件是否为空，否“✅”，是“-”
• Chapters：章节是否为空，否“✅”，是“-”
• Description：段落描述是否为空
>> 均为空，则“-”
>> 部分为空，则提示哪部分，如“Para 2 missing”
>> 均不为空，则“Full“
• Updated：记录保存更新时间
• Action：Creat、Edit
4
支持批量操作
• Bulk Publish：支持多选指定产品（草稿），批量发布
• Bulk Export：支持多选指定产品，批量导出做内容审计
• Bulk Delete：支持多选指定产品，批量清空内部内容，⚠️不是删除产品，清空需二次确认

📌 Videos 模块 编辑页 说明索引
Watch Page
1
操作
• Cancel：取消编辑；
• Save：保存编辑；
• Publish：发布&重新发布，watch page页面更新，重新向谷歌提交更新信息；
Basic Information 基础信息
2
Linked Product
• 展示产品名（Model），系统自动填入，不可编辑。
数据库字段：product_id FK
3
URL Slug
• 记录视频别名
• 初始默认 = 产品 slug + -demo，可按需修改
• 需保证唯一性。
• 可通过产品配置创建获取初始值。
数据库字段：slug VARCHAR(255) UNIQUE
4
H1 Title
• 视频一级标题
• 默认拼接：{Product Name} — Complete Setup Demo Video
• 可通过产品配置创建获取初始值。
数据库字段：h1_title VARCHAR(200) · 用于：页面 H1 + JSON-LD name
5
Publish Date
• 记录发布时间，不可编辑
• 未有发布记录时，值为空
• 发布后，记录发布时间，在重新发布前值维持不变
6
Status
• 展示视频状态，不可编辑
>> Not Created：未在产品配置页触发创建或在Videos模块中未经点击Creat的产品
>> Draft：已创建，未有过发布记录的记录，在save draft后，状态为Draft
>> Published：已发布且未再有更新内容的记录，状态为Publish
>> Updated：已发布，更新新内容后，在save draft后，状态为Updated
Video & Captions
区别产品页Hero Video的内容
5
Long-form Video
与详情页主视频不同的文件：
• Hero (详情页) = 30 秒精剪
• Watch (Watch Page) = 45-90 秒完整版
OSS 路径 /videos/watch/{slug}.mp4
数据库字段：watch_video_url + video_duration（自动检测）
6
VTT Captions (Strongly Recommended)
Google 能读字幕 = 免费 SEO 文本量。
没字幕也能发布，但效果打折。
数据库字段：caption_vtt_url VARCHAR(500) NULL
7
Description Para 1 (Required)
100-200 字符
必须在 HTML 中可见，不只在 JSON-LD（否则 Google 忽略）。
数据库字段：description_para_1 TEXT
Inherited Thumbnails
8
Thumbnails (Inherited, Replaceable)
默认沿用 Hero Video 的 3 张缩略图。
推荐：替换为长版视频首帧，与新视频视觉一致。
数据库字段：thumbnail_16x9 / thumbnail_4x3 / thumbnail_1x1
Optional
9
Chapters (Optional)
配置后生成 JSON-LD 的 Clip + SeekToAction，搜索结果可能显示"跳转到第 X 秒"。
不配置不影响收录。
数据库表：watch_page_chapter（N:1）
10
Related Videos (Optional)
不选 = 系统按同类目自动推荐。
数据库表：watch_page_related（N:N）
Hidden Logic (After Save)
A
Pre-publish Validation
• Required missing → can save as Draft, cannot Publish
• Strongly recommended missing → can Publish, but warning modal pops up
B
Status State Machine
Not Created → Draft（创建时）→ Published（必填齐全后）
Published 可改回 Draft（下线）
数据库字段：status TINYINT (0=Draft, 1=Published)
