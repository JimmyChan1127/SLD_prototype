改造区 #1：主视觉（1期）
1
缩略图修改布局为横向且第 1 位插入"视频缩略图"
• 默认 active 状态
• 原营销主图变为第 2 张
• 用户点击可在视频/图片间切换
数据源：缩略图 poster 来自 product_hero_video.thumbnail_16x9
2
主显示区默认渲染 video 元素
属性：自动播放，初始静音播放，自动循环播放

SEO 红线：
• <video> 必须在初始 HTML 中存在，禁止 JS 后注入
• 视频首屏可见，不能在 tab / accordion 里
• display:block 不能 hidden
• 这是 Google 识别"主视频"的核心信号
数据源（详见 Prototype 03a）：
• video.src ← product_hero_video.hero_video_url
• video.poster ← product_hero_video.thumbnail_16x9
• JSON-LD name ← video_title
• JSON-LD description ← video_description
• JSON-LD duration ← PT{video_duration}S
• JSON-LD uploadDate ← upload_date
改造区 #2：Watch Page 入口（2期）
3
Watch Page 互链卡片
• 位置：缩略图 下方
• 链接到 /videos/{slug}-demo
• 仅当 Watch Page 已发布时显示（发布状态为草稿/未启用时，自动隐藏）
• 用品牌青绿色，与周围内容明显区分

作用：
① 给用户提供完整观看入口
② 给 Watch Page 提供内链权重
③ 提示 Google 该产品有独立 Watch Page
数据源（详见 Prototype 03b）：
• 是否显示 ← watch_page.status = 1 (Published)
• 链接 URL ← /videos/{watch_page.slug}
不改动区域
—
非上述提到的改动区域：全部维持现状
